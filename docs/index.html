Bioinformatics Validation Project

Computational Validation of USAG-1 (SOSTDC1)
as a Human Tooth Regeneration Target

A six-module bioinformatics framework to independently validate the mechanistic, structural, and translational evidence underlying the TRG035 Phase I clinical trial — from gene expression atlas mining to ML-based biomarker discovery.

Scientific Rationale

Why Computational Validation Matters Here

Blocking USAG-1 — a BMP antagonist and Wnt signaling modulator — removes a developmental brake on tooth germ activation, enabling a third dentition in mammals. The critical question is whether this mechanism is conserved and therapeutically accessible in adult humans.
— Core hypothesis driving TRG035 (anti-USAG-1 antibody), Phase I, Japan 2024

The Japanese team's work has progressed from a 2021 Scientific Reports mouse study through to a completed Phase I single-dose safety trial (TRG035) in 30 adult men with molar agenesis. While the clinical safety endpoint is now answerable, the mechanistic and translational biology remain computationally unvalidated using current public multi-omic resources.

This project bridges that gap. It does not replicate the clinical trial — it provides independent, data-driven validation of the biological premises that justify taking this therapy into humans: tissue-specific expression, protein interaction architecture, structural druggability, variant-phenotype correlation, pathway conservation across species, and biomarker feasibility.

Biological Background

USAG-1, encoded by SOSTDC1, is a secreted protein belonging to the DAN/Cerberus family of BMP antagonists. It exerts dual inhibition: (1) direct binding to BMP-2, BMP-4, and BMP-7, blocking their receptor engagement; and (2) modulation of canonical Wnt signaling through interaction with the co-receptor LRP5/6. Both pathways are rate-limiting for odontogenesis — the embryonic program responsible for tooth formation.

In wild-type adult mice, tooth germ rudiments exist but are developmentally arrested. USAG-1 knockout or anti-USAG-1 antibody administration restores BMP-Wnt signaling sufficiently to reactivate these rudiments. Whether equivalent rudimentary structures exist in adult humans, and whether their signaling circuitry is sufficiently conserved, is the translational crux this project addresses computationally.

Key gap addressed: No published study has cross-validated USAG-1's BMP/Wnt dual-inhibition mechanism using current human single-cell transcriptomics, population-scale variant data, or structural docking against the clinical antibody's inferred epitope — this project does all three.
Project Architecture

Six Validation Modules

Each module maps onto a distinct validation question, is independently executable, and produces a deliverable artifact (figure, network, model, or table) suitable for publication.

MOD-01 Gene Expression & Tissue Specificity
Goal

Confirm where and when SOSTDC1 is expressed in human dental tissues using publicly available bulk RNA-seq and single-cell atlases. Quantify expression across cell types in gingiva, dental pulp, jaw, and kidney (the primary expression site).

Perform differential expression analysis across tooth developmental pseudotime trajectories. Identify co-expressed gene modules using WGCNA to map the USAG-1 regulatory neighborhood in each tissue compartment.

Seurat Scanpy DESeq2 edgeR WGCNA GEO2R CellxGene
📊 Output: Cell-type expression atlas · Co-expression network
MOD-02 Protein–Protein Interaction Network
Goal

Build and analyse a high-confidence PPI network centred on USAG-1/SOSTDC1 using STRING, BioGRID, and IntAct. Confirm the key regulatory nodes: LRP5, DKK4, BMP2, BMP4, and BMP7. Score edge confidence and compute network topology metrics (betweenness centrality, clustering coefficient, hub score).

Perform cross-species comparison of the human vs. mouse interactome to quantify translational fidelity — the degree to which the mouse KO biology predicts human responses to TRG035.

STRING API Cytoscape NetworkX igraph BioGRID IntAct
🕸 Output: Annotated PPI graph · Cross-species conservation score
MOD-03 Structural Biology & Antibody Docking
Goal

Computationally validate the TRG035 mechanism using the AlphaFold2 model of USAG-1 (UniProt Q6X4U4). Dock BMP-7 and LRP5/6 peptides to define the two binding interfaces independently. Confirm the published finding that blocking the BMP-binding interface (not LRP5/6) is the functional mechanism of tooth induction.

Run molecular dynamics simulation to assess interface stability and identify druggable pockets via virtual screening. Map TRG035's inferred epitope residues onto the structure and compute binding free energy estimates.

AlphaFold2 AutoDock Vina HADDOCK GROMACS PyMOL FPocket
🔬 Output: Docked complex structures · Binding free energy table
MOD-04 Variant & Mutation Analysis
Goal

Query gnomAD, ClinVar, and OMIM for SOSTDC1 population-scale variants. Classify variants by predicted functional impact using PolyPhen-2, SIFT, CADD, and EVmutation. Map damaging variants onto the AlphaFold structure to identify interface-disrupting mutations.

Identify variants that segregate with hypodontia phenotypes and model whether they alter the BMP or Wnt binding interface — this predicts which patient sub-populations are most likely to respond to TRG035, directly informing Phase II stratification.

gnomAD ClinVar PolyPhen-2 SIFT CADD HOPE Tool EVmutation
🧬 Output: Variant-function map · Patient stratification model
MOD-05 Pathway Enrichment & Cross-Species Conservation
Goal

Validate that BMP/Wnt signaling disruption in mouse USAG-1 KO models translates biologically to human dental transcriptomes. Perform GSEA and pathway enrichment (KEGG, Reactome, GO) on SOSTDC1 co-expressed gene sets in both species.

Use biomaRt for ortholog mapping between human and mouse. Build a quantitative pathway conservation score — a key metric for interpreting TRG035's translational validity. Report discordant pathways as potential safety flags.

fgsea clusterProfiler g:Profiler biomaRt KEGG Reactome
📈 Output: GSEA plots · Cross-species conservation matrix
MOD-06 ML-Based Biomarker Discovery
Goal

Identify a transcriptomic biomarker signature in accessible biofluids (blood or saliva) that correlates with BMP pathway activation — a proxy for pharmacodynamic response to USAG-1 inhibition. This addresses the critical unmet need in the TRG035 trial: how do you know the drug is working before tooth formation is visible?

Apply LASSO regression and random forest feature selection to BMP-pathway gene sets across public dental/systemic datasets. Validate the signature via cross- validation and external cohort testing.

scikit-learn glmnet limma Random Forest LASSO SHAP
🤖 Output: Biomarker gene signature · ROC / AUC validation

Integration Logic

Modules 1–2 establish the expression and interaction context. Module 3 tests structural mechanistic claims. Module 4 identifies patient-stratification signals. Module 5 validates cross-species translation. Module 6 produces the only output with direct clinical utility in the ongoing trial: a pharmacodynamic biomarker.

Project Plan

Execution Timeline (12 Weeks)

WK 1–2

Environment Setup & Data Acquisition

Configure R / Python environments, Conda env files, Snakemake workflow. Download and version-pin all GEO accessions, UniProt structures, gnomAD VCF. Set up GitHub repository with README, CITATION.cff, and data manifest.

WK 3–4

Module 1 — Expression Atlas

Process scRNA-seq datasets (QC, normalisation, clustering, cell-type annotation). Generate SOSTDC1 expression violin plots, UMAP embeddings, and co-expression modules per tissue.

WK 5

Module 2 — PPI Network

Build STRING network, export to Cytoscape, compute topology metrics. Cross-species ortholog mapping via biomaRt. Generate network visualisation with hub annotation.

WK 6–7

Module 3 — Structural Docking

Prepare AlphaFold model, dock BMP-7 and LRP6 peptides, run short MD equilibration. Compute MM-GBSA binding free energies. Visualise epitope surfaces in PyMOL.

WK 8

Module 4 — Variant Analysis

Pull gnomAD / ClinVar variants, run in silico pathogenicity scoring, map onto USAG-1 structure. Generate variant-effect matrix highlighting interface-disrupting mutations.

WK 9

Module 5 — Pathway Enrichment

Run GSEA for BMP / Wnt gene sets in human and mouse co-expression data. Compute cross-species pathway conservation score. Flag discordant pathways as translational risk signals.

WK 10–11

Module 6 — Biomarker ML Model

Curate BMP-response transcriptomic datasets from saliva / blood. Train LASSO and random forest models. Evaluate performance (ROC-AUC, precision-recall). Generate SHAP explainability plots.

WK 12

Integration, Figures & Manuscript Draft

Assemble cross-module findings. Generate publication-quality figures (ggplot2, matplotlib). Write results, discussion, and supplementary methods. Publish GitHub release v1.0.
